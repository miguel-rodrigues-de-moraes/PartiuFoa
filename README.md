# PartiuFOA

Uma plataforma web desenvolvida para facilitar a conexão entre estudantes universitários que oferecem ou procuram caronas para seus deslocamentos até a faculdade.

## Sobre o projeto

O projeto tem como objetivo desenvolver uma solução que facilite a organização de caronas entre estudantes, permitindo que usuários encontrem pessoas que realizam trajetos semelhantes e diminua o volume e os problemas apresentados pelo transporte público da uniFOA (Foão)

A proposta busca tornar o deslocamento até a universidade mais prático, além de incentivar o compartilhamento de veículos entre estudantes.

## Objetivos

* Facilitar a busca por caronas universitárias;
* Conectar estudantes que possuem trajetos semelhantes;
* Auxiliar na organização dos deslocamentos até a universidade;
* Desenvolver uma interface simples e intuitiva;
* Aplicar na prática conhecimentos de desenvolvimento web.
* Expandir a comunicação entre diferentes alunos e cursos

## Funcionalidades

* Cadastro e interação entre usuários;
* Busca por caronas;
* Visualização de informações sobre os trajetos;
* Oferta de caronas;
* Interface responsiva;
* Navegação entre as páginas da aplicação.

## Como executar

### 1. Clone o repositório

*git clone URL_DO_REPOSITORIO*


### 2. Acesse a pasta do projeto

*cd caronas-universitarias*


### 3. Execute o projeto

*Abra o arquivo `index.html` em um navegador.*

Também é possível utilizar uma extensão como o **Live Server** no Visual Studio Code para executar o projeto localmente.

## Funcionamento

O usuário pode acessar a plataforma e visualizar as opções de caronas disponíveis.

A aplicação utiliza JavaScript para passar da página index para a homepage do projeto e melhorar a qualidade das mensagens de erro, conforme o que a pessoa erre a mensagem muda.
